# 国学梦数据导入说明

数据源：<https://www.guoxuemeng.com/guoxue/shijing/>（国学梦·诗经带拼音）。抓取脚本 `scripts/scrape-guoxuemeng.py`，原始数据 `data-sources/guoxuemeng-shijing.json`，
导入脚本 `scripts/import-guoxuemeng.mjs`，之后 `npm run reading:generate` 生成每首诗的注音（`src/data/reading/<id>.json` 的 `py` 字段）。

## 覆盖范围

- 305 篇全部抓取，正文与注音逐字对齐（音节数 = 汉字数）。
- 笙诗六篇（南陔等）源站只有篇名没有内容，站点也没有收录，**未导入**。
- 标题、分类、注释、今译保持原样。源站篇名与站点不同的只有：#8 芣苡（源站：芣苢）、#24 何彼襛矣（源站：何彼秾矣）、#152 鳲鸠（源站：鸤鸠）、#164 棠棣（源站：常棣）、#230 绵蛮（源站：緜蛮）、#237 绵（源站：緜）。

- 緜：页面「捄之陾陾」只写了一个「陾」（注音也只有一个 réng）；补成「陾陾」，两个字都读 réng。
- 卷阿：「菶々」的叠字符号「々」展开为「菶菶」。

## 注音

与旧版逐字比较，约 947 个汉字读音变化，主要是车 jū、济 jǐ、锡 cì 等。源站标注的连读变调在抓取时先还原为本调，再由 `applySandhi` 统一重新标注变调（2026-11-28 站长改定）。纸质书校正（`scripts/book-overrides.mjs`）在生成时最后套用。
源站把「子」标成轻声 zi（9 处），保持源站写法。

## 今译和注释（2026-11-28）

站长指定今译、注释也以国学梦为准。`python3 -I scripts/scrape-guoxuemeng-notes.py` 抓取每篇页面的「解释翻译」（只取第一种译文）和「注释出处」，存为 `data-sources/guoxuemeng-notes.json`；`node scripts/import-guoxuemeng-notes.mjs` 写入 `src/data/poems.json`。

- 今译 305 篇全部换成国学梦译文，每章一段。
- 注释：国学梦有注释的 242 篇换成国学梦注释（一条一行）；没有注释的 63 篇保留站内原注释。
- 每篇记录出处 `sources: { translation, annotation }`，阅读页底部显示「参考：国学梦」链接。
- 正文注音不随注释改动。注释括号里的读音和正文注音不一致的地方列在 `docs/notes-pinyin-conflicts.md`，需要人工核对。
