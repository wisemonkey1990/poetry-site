# 注音来源：古文之家《诗经拼音版》

2026-11-28 起，站内诗文注音**全盘采用**古文之家《诗经拼音版》（www.cngwzj.com，2024 年 8 月，大字全本注音）。

- 数据：`data-sources/cngwzj-shijing.json`，由该本 PDF 转文字稿与站内正文逐字对齐得到；`-` 表示两边用字不同、没能对齐的字。
- 生成：`scripts/generate-reading-data.mjs` 里该本读音优先级最高；`-` 的字回退到国学梦注音 + 纸质书校正（`scripts/book-overrides.mjs`）。对齐失败共约 960 字（占 3%）。
- 不/一：统一变调（不+去声 bú；一+去声 yí；一+阴阳上 yì；句末、后面是标点的保持本调），规则在生成时套用，覆盖该本自己的标法。
- 书中把 jū/qū/xū 排成 jǖ/qǖ/xǖ 的笔误已改回 ū；《大雅》来许一处的 yǜ 不采用。
- 读者纠错改过诗文的篇目，若汉字与对齐时不同，该篇不使用该本读音，回退到旧流程。
- 重新生成：`npm run reading:generate`。

与纸质书校正冲突的以该本为准：施于松上 / 施于条枚等 4 处由 yì 改为 shī。
